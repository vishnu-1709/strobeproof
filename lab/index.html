Is it safe to post?

Drop a GIF, WebP, PNG or video. Strobeproof checks every frame against the WCAG 2.3.1 flash thresholds, in your browser. Nothing is uploaded, and the file is never played on screen.

1. Choose a file

or drag a file onto this box

2. How big will it be on screen?

Flashing that covers a small area is allowed. The limit depends on the displayed size.

1024 is the WCAG reference screen.

3. Only part of the frame? (screen recordings)

For the benchmark: crop a screen recording to where the test clip was shown. Measured in the recording's own pixels. With "At its own size", the region's size is used as the displayed size; set the screen width to the recording's width.

Details

Thresholds: WCAG 2.3.1 Three Flashes or Below Threshold. Strobeproof reduces exposure; it is not a medical device. Results assume WCAG reference viewing conditions.
